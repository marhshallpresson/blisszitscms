# **App Name**: Blisszits CMS

## Core Features:

- Workspace Management: Enable users to create and manage multiple workspaces to organize content.
- Content Dashboard: Provide a dashboard view of content calendars, drafts, and published posts within each workspace.
- Content Creation and Editing: Allow users to create, edit, and schedule content with fields for titles, descriptions, scripts, and due dates.
- AI Content Inspiration: Suggest content ideas and titles using a generative AI tool based on trending topics and user preferences.
- Reminder System: Enable push and email notifications for content deadlines and reminders.
- Anonymous Authentication: Use Firebase for anonymous authentication to provide a unique and persistent workspace for each user without requiring personal login credentials.
- Set Content Status: Allow users to set a status on content pieces (draft, in progress, for review, approved, published)

## Style Guidelines:

- Primary color: Purple (#6366F1) for creativity and focus.
- Background color: Light gray (#F9FAFB) for a clean, modern look.
- Accent color: Blue (#3B82F6) for interactive elements and highlights.
- Body font: 'PT Sans' (sans-serif) for readability and a friendly feel.
- Headline font: 'Playfair' (serif) for elegant headlines and titles.
- Use consistent and modern icons from Lucide to represent actions and content types.
- Employ a clean and structured layout with clear sections for navigation, workspace selection, and content management.
